# 블라인드 미팅 플랫폼 — 구현 가이드

Desk에서 `/meeting` 커맨드를 실행하면 열리는 WAM 앱입니다. 미팅 모집 → 매칭 → 단체 채팅 → 장소 추천·예약 →
미팅 진행 콘텐츠 → 익명 애프터 → 개인 채팅 → 후기 → 기록·학과 통계까지 한 앱에서 처리합니다.

## 실행하기

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm build:cloudflare
corepack pnpm db:migrate:local      # 0002~0007 마이그레이션 적용
corepack pnpm dev:cloudflare        # http://127.0.0.1:8787
corepack pnpm test                  # 서버 로직 테스트 (in-memory SQLite)
corepack pnpm test:cloudflare       # 로컬 Worker에 서명 요청을 보내는 스모크 테스트
```

실제 화면은 Desk의 WAM 컨텍스트가 필요하므로 공통 해커톤 채널의 `앱_개발_검증` 그룹에서 `/meeting`으로 확인합니다.

## 혼자서 전체 흐름 시연하기

1. `/meeting` 실행 → 프로필(학과·학번·나이·성별) 저장
2. **미팅 모집하기**로 모집글 작성 (예: 2:2, A팀 = 내 학과, B팀 = 다른 학과)
3. 미팅 상세 → **🧪 데모 참가자로 채우기** (남은 자리를 "데모" 표시 참가자가 채움 → 즉시 매칭·단체 채팅 생성)
4. **장소** 탭에서 추천 장소 확정, 예약 일정 공유
5. **미팅 진행** 탭에서 **데모 60배속**으로 시작 → 75분 분량의 타임라인이 약 1분 20초에 지나감
   (질문·미션·이벤트·대화 주제가 단체 채팅에도 자동 게시됨)
6. 45분 단계부터 사랑의 짝대기, 75분 단계부터 **애프터** 탭 열림 → 익명 선택 제출
7. 데모 참가자 중 일부가 맞선택을 하므로 개인 채팅방이 열림 → 연락처 교환 동의 흐름 확인
8. **후기** 탭, 하단 **기록** / **통계** 탭 확인

데모 참가자는 통계 집계에서 제외됩니다.

## 설계 결정

- **단체·개인 채팅은 앱 안(D1)에 직접 구현했습니다.** Channel App SDK 0.17.2의 네이티브 API에는 그룹 채팅 생성이
  없어서(메시지 전송·조회만 가능) 자동 생성 대신 앱 내 채팅방을 사용합니다. 3초 간격 폴링입니다.
- **진행 콘텐츠는 크론 없이 동작합니다.** 누군가 진행 화면을 열어 폴링할 때 시작 시각 기준으로 도래한 단계를
  1회만 생성(`INSERT OR IGNORE`)하고 채팅에 게시합니다. 질문·미션은 미팅 ID로 결정되어 모든 참가자에게 동일합니다.
- **신원 보호.** 모든 Function은 서명된 컨텍스트의 `caller.id`로 본인을 식별하고, 응답에는 매니저 ID가 포함되지
  않습니다. 참가자는 미팅별 멤버 번호로만 서로를 가리킵니다.
- **애프터 선택은 재제출 불가**이며, 일치하지 않는 선택은 어떤 응답에도 나타나지 않습니다.
- 장소 데이터는 **데모용 샘플**(가상 업체)입니다. 제휴 시 `places-data.ts`의 `perk`가 할인·쿠폰으로 노출됩니다.
- 동시 신청은 `INSERT … SELECT … WHERE (인원 < 정원)` 단일 문으로 정원을 지킵니다.

## 운영진에게 요청할 것

1. **원격 DB 마이그레이션 적용**: `0002_profiles.sql` ~ `0007_reviews.sql` (모두 신규 테이블 추가, 삭제 없음).
   코드는 새 스키마에 의존하므로 **적용 완료 후** main에 머지하세요.
2. **익스텐션 등록 갱신** (`pnpm register`): 커맨드가 `tutorial` → `meeting`으로 바뀌었고 Function이 추가되었습니다.
3. 추가 권한은 필요하지 않습니다 (기존 `writeGroupMessage*` 권한은 더 이상 사용하지 않습니다).

## 알려진 한계

- 커맨드가 `desk` 범위이므로 앱은 채널 **매니저** 계정에서만 열립니다 (해커톤 시연은 팀원이 매니저로 참여).
- 채팅 알림은 앱 안에서만 표시됩니다 (푸시 없음).
- 통계는 표본이 적으면 "표본 적음" 배지가 붙습니다 (후기 3건 미만).
